# Faust libraries: new functions and illustrated documentation

*August 2026 — `claude` branch of [grame-cncm/faustlibraries](https://github.com/grame-cncm/faustlibraries).*

This work brings two things to the Faust libraries: **new DSP functions**, and an **illustrated documentation** — SVG figures embedded in the library pages at [faustlibraries.grame.fr](https://faustlibraries.grame.fr), each one generated from a compiled Faust probe and validated by property assertions.

## Illustrated documentation

**157 SVG figures** are now embedded in 24 pages of the online documentation. Every figure is produced by `make plots` from a *compiled Faust probe* — the curve shows what the library actually computes, not a reimplementation — and the generator embeds *property assertions* (the lowpass must be −3 dB at its cutoff, the compressor slope must match its ratio, the band-limited saw must beat the naive one's alias floor): it fails rather than publish a figure that contradicts the function's name.
